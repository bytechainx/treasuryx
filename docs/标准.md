# treasuryx 标准文档

**crate**：`treasuryx` v0.1.0 | **角色**：美国财政部源事实的离线类型层

> 采集范围权威：`specs/adapter/treasury.md`；跨源语义权威：`contracts/cross-source-routing.md`。
> 本文件只描述本库的能力标准，不改变任何授权状态。

---

## 1. 需求标准

### 目标

把美国财政部 Fiscal Data 等源侧的**源事实**表达为稳定 Rust 类型：数据集常量、记录值对象、
离线解析、路由与主权守卫、fail-closed 授权判定与 publication 语义。

### 边界

- **包含**：`TreasuryDatasetId` / `NyFedDatasetId` / `FredValidationSeries` 三个 ID 枚举与常量集、
  `TreasuryRecord` 值对象与 Fiscal Data 信封、采集面与曲线路由与写入主权三类守卫、
  `TreasuryAuthorization` 判定、`TimePrecision` / `AvailabilityEvidence` / `PitEligibility` 三元组
- **不包含**：联网采集、live、凭据管理、代理、单位换算、派生指标、存储与分发
- **依赖**：`thiserror`、`serde`、`serde_json`（无 HTTP 客户端、无异步运行时、无日期库）
- **零内部耦合**：不依赖任何 `bytechainx/*` crate，无 `path` 依赖

## 2. 设计标准

### 架构

```text
treasuryx
├── error   — TreasuryError / TreasuryErrorKind / TreasuryResult
├── value   — Date / Period / Frequency / Unit（基础值对象）
│   ├── value/datasets — 三个 ID 枚举、常量集与三类守卫
│   └── value/record   — TreasuryRecord / TreasuryAmount / validate_record
├── authz   — TreasuryAuthorization 与 fail-closed 判定
├── pit     — publication 语义三元组
└── parse   — parse_treasury_records（离线、无网络参数）
```

依赖方向单向：`error` ← `value` ← {`authz`, `pit`, `parse`}；`error` 不依赖任何同级模块。

### 数据流

```text
合成样本 JSON（字符串）
  → parse_treasury_records：顶层 / meta / data 行的字段白名单（未知字段原子失败）
  → TreasuryDatasetId::parse_id：曲线产品路由、未知 ID 拒绝
  → guard_collection_dataset：采集面守卫（DS01 / DS05 放行）
  → Period::parse_day：严格 YYYY-MM-DD
  → validate_record：完整性校验
  → TreasuryEnvelope { records, meta }
```

## 3. 数据集与采集面

**Phase 1 数据集全集（`PHASE1_DATASETS`）**：`DS01`–`DS10`（DTS 现金余额 / DTS 存取款 /
DTS 公共债务交易 / 国债拍卖结果 / Debt to the Penny / 日度收益率曲线 / 实际收益率 /
MTS 月度收支 / 未偿证券明细 MSPD / 利息支出）。

**本域采集面（`WIRE_COLLECT_DATASETS`）**：**`DS01` + `DS05`**（最小集）。
`guard_collection_dataset` 的判据：

| 数据集 | 结论 | 错误分类 |
| --- | --- | --- |
| `DS01` / `DS05` | 放行 | — |
| `DS06` / `DS07` | 拒绝（曲线，路由 `yieldx`） | `RoutedElsewhere` |
| `DS04` | 拒绝（lossy skeleton map，禁作拍卖事实源） | `SemanticallyRejected` |
| `DS02` / `DS03` / `DS08` / `DS09` / `DS10` | 拒绝（Phase-1 采集面外） | `NotApplicable` |

频率（取自清单 §1.1）：`DS01`–`DS03` / `DS05`–`DS07` 日频，`DS04` 事件，
`DS08`–`DS10` 月频。

## 4. 曲线路由

`DS06`（日度收益率曲线）与 `DS07`（实际收益率 TIPS）是**曲线产品**，
MUST NOT 被自动映射为普通观测，MUST 被拒绝并路由 `yieldx`。

- `is_curve_product(dataset_id)`：判断是否为曲线产品（`DS06` / `DS07`）
- `guard_curve_product(dataset_id)`：曲线产品 → `RoutedElsewhere`
- `TreasuryDatasetId::parse_id` 对 `DS06` / `DS07` **fail-closed**（不得解析成功）
- 解析器对 `_dataset` 为 `DS06` / `DS07` 的样本一律拒绝

---

## 5. 写入主权与校验面

决策 `WALCL-AUTHORITY-2026-08-20-A`（选项 A）：`WALCL` / `WTREGEN` / `RRPONTSYD` / `WRESBAL`
的权威 Observation 唯一写入方为 `fredx`。

- `FD_VALIDATION_SERIES`：`FD01`–`FD04` 四个校验序列（`WALCL` / `WTREGEN` / `RRPONTSYD` / `WRESBAL`）
- `is_validation_only_series(series_id)`：该 series 是否属永久校验面
- `guard_write_authority(series_id)`：命中校验面 → `WriteAuthorityDenied`
- `FredValidationSeries::canonical_write_owner()` 恒为 `fredx`

**对账语义**：校验面 MUST 只**告警**，MUST NOT 覆盖权威值，MUST NOT 双写 canonical key。

**单位风险（不得静默换算）**：`RRPONTSYD` 的源单位是 **Billions of U.S. Dollars**，
而 `WALCL` / `WTREGEN` 为 **Millions**。`unit_for_validation_series` 具名表达该差异；
`WRESBAL` 未在单位风险条中登记，故记 `Unit::Unknown`（不得由序列名推断）。

## 7. 解析与合成夹具

**输入形态**：Fiscal Data 信封形态的单一 JSON 对象。

- 顶层键白名单：`_synthetic`、`_note`、`_dataset`、`data`、`meta`
- `meta` 键白名单：`count`、`total-count`、`total-pages`（`required_u64` 接受 JSON 数字或纯数字字符串）
- `DS01` 行键白名单：`record_date`、`account_type`、`open_today_bal`、`close_today_bal`
- `DS05` 行键白名单：`record_date`、`debt_held_public_amt`、`intragov_hold_amt`、`tot_pub_debt_out_amt`
- `_dataset` 为**合成夹具的标注字段**（真实源信封不具备），用于声明行归属
- 日期必须严格 `YYYY-MM-DD`（月 / 日两位补零）

**原子失败与重复身份**：出现白名单外的字段 → `SemanticallyRejected`（原子失败，不部分成功）；
重复身份（`DS01` = 数据集 + 日期 + 账户类型；`DS05` = 数据集 + 日期）→ **拒绝**
（本库**不做**静默去重）。金额缺失 MUST 具名表达（`SourceOmitted` / `ExplicitNull`），
MUST NOT 静默转 0；记录内**至少一个**金额可用，否则报 `Missing`。

**合成样本层面的自洽不变量**：本库要求 `meta.count` 等于 `data` 行数，否则报 `Invalid`。
该不变量只在**本库的合成样本层面**成立——清单 §7 把 Fiscal Data 的分页语义与字段字典登记为
**部分收敛 / 仍 UNKNOWN**，故本库**不**据此对真实 Fiscal Data API 的信封语义作出任何结论。
保留该检查的理由是 fail-closed：不满足即拒绝，失败面安全（拒绝而非放行）。

**合成夹具声明**：`tests/fixtures/` 下的全部文件均为本特性**自拟的合成样本**，
**不是真实源数据**，**不构成任何证据**；不得被表述为「实测」「核验 PASS」或任何证据等级。
夹具字段名对齐 `specs/adapter/treasury.md` 声明的数据集与字段，不编造清单未提到的端点或字段。

## 8. publication 语义

| 项 | 值 |
| --- | --- |
| `TimePrecision` | `Date` |
| `AvailabilityEvidence` | `Inferred` |
| `PitEligibility` | `NotEligible` |

`is_formal_pit_eligible()` 恒为 `false`：Fiscal Data 无官方发布时刻字段，亦无 Owner 签批日历。
MUST NOT 补造 `00:00 UTC` 把 `Date` 伪装成 `Instant`；日后接入官方字段或经签批日历时须同步
更新清单与本文件，**禁止静默升格**。

## 9. 非目标与门禁

**非目标**：不做联网采集与 live（须另批决策 ID + B2–B8 门禁）、不做凭据与代理、
不做单位换算、不做派生指标（净流动性 / TGA 脉冲 / 财政脉冲等归 analytics）、
不写权威 canonical key、不做存储与分发、不做 PIT 升格。

**源码面硬断言（可执行）**：`tests/sdd_spec.rs` 的 S-9 在**运行期递归枚举** `src/` 下全部
`.rs`（以 `CARGO_MANIFEST_DIR` 为根，新增文件自动纳入），逐个断言不含 `http://` / `https://`
端点字面量、不含 `env::var` / `from_env` 凭据读取。

**门禁**：

```bash
cargo fmt --all -- --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-features
cargo package --no-verify
```

**诚实边界**：`production_decision = NO-GO`；清单 COMPLETE ≠ ship；
`TREASURY-B1-2026-08-20-OFFLINE` 只覆盖 **offline fixture** 范围（live 须另批）。
